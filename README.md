<a name="português"></a>
## 🇧🇷 Português

**"Seu espaço, suas ideias."** Uma plataforma web desenvolvida como projeto avaliativo do curso Técnico em Desenvolvimento de Sistemas (SESI/SENAI-SP), criada para conectar jovens a conteúdos de música, games, ciência, arte e experiências culturais em um só lugar.

🔗 **Acesse o projeto online:** [brunossilva12-creator.github.io/projeto-conecta-jovem](https://brunossilva12-creator.github.io/projeto-conecta-jovem/)

### ✨ Funcionalidades e Seções
- **Navegação Multipáginas:** Estrutura organizada com páginas dedicadas para **Início**, **Galeria** e **Sobre**.
- **Três Pilares de Conteúdo:**
  - **🎮 Cultura Pop:** Jogos, música, cinema e tendências da geração.
  - **🎨 Criatividade:** Espaço voltado para arte, fotografia e novas ideias.
  - **🔬 Descobertas:** Exploração de ciência, tecnologia criativa e curiosidades.
- **Galeria Interativa:** Vitrine visual com histórias e experiências para navegar diretamente pelo site.
- **Design Responsivo:** Interface moderna adaptada para diferentes dispositivos.

### 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica das múltiplas páginas (`Início`, `Galeria` e `Sobre`).
- **CSS3:** Estilização visual, tipografia, cartões de destaque e layout responsivo.
- **JavaScript:** Interatividade e navegação na galeria do projeto.

### 🚀 Como executar localmente
1. Clone este repositório:
   ```bash
   git clone https://github.com/brunossilva12-creator/projeto-conecta-jovem/tree/main
   ```
2. Abra a pasta do projeto e execute o arquivo `index.html` diretamente no seu navegador.

## 🇺🇸 English

**"Your space, your ideas."** A web platform developed as an evaluative project for the Systems Development Technical Course (SESI/SENAI-SP), designed to connect young people with music, games, science, art, and cultural experiences in one place.

🔗 **Live Demo:** [brunossilva12-creator.github.io/projeto-conecta-jovem](https://brunossilva12-creator.github.io/projeto-conecta-jovem/)

### ✨ Features & Sections
- **Multi-Page Navigation:** Organized structure featuring dedicated **Home**, **Gallery**, and **About** pages.
- **Three Content Pillars:**
  - **🎮 Pop Culture:** Games, music, cinema, and youth trends.
  - **🎨 Creativity:** Focused on art, photography, and new ideas.
  - **🔬 Discoveries:** Exploration of science, creative technology, and curiosities.
- **Interactive Gallery:** Visual showcase with stories and experiences to explore directly on the site.
- **Responsive Design:** Modern interface adapted for both desktop and mobile screens.

### 🛠️ Technologies Used
- **HTML5:** Semantic structure across multiple pages (`Home`, `Gallery`, and `About`).
- **CSS3:** Visual styling, typography, highlight cards, and responsive layout.
- **JavaScript:** Interactivity and gallery navigation features.

### 🚀 How to run locally
1. Clone this repository:
   ```bash
   git clone https://github.com/brunossilva12-creator/projeto-conecta-jovem/tree/main
   ```
2. Open the project folder and launch the `index.html` file in your browser.
