SOBRE O PROJETO

Ideias que se conectam

O Conecta Jovem é uma experiência web cirada para explorar temas presentes no cotidiano dos estudantes: Cultura, criatividades e descobertas

Missão

Valorizar interesses e estimular a curiosidade dos jovens.

Tecnologias

HTML para estrutura, CSS para apresentação e JavaScript para interações.

Recursos

Menu responsivo, filtros, mosaico e modal com navegação
